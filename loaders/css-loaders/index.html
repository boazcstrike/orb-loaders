CSS Loaders — eight ring and orb loaders

Picked from css-loader by Vineeth TR and reworked. Each is one element and plain CSS: no JavaScript, no markup beyond a span. They take their colour from currentColor and their size from --cl-size, so they follow the page theme without a theme option.

One loader, every size

Dropping it into a page

One stylesheet, no build step, no dependency.

HTML 
<!-- load it -->
<link rel="stylesheet" href="css-loaders.css">

<!-- use it: one element, announced as a status -->
<span class="cl-arc" role="status" aria-label="Loading"></span>

<!-- size and colour -->
<span class="cl-orbit" style="--cl-size: 96px; color: #0f766e"
      role="status" aria-label="Loading"></span>

<!-- freeze it while offscreen (optional) -->
el.classList.add('cl-paused');
  • Cost: about 11 KB raw including the licence header. Every animation runs on transform and opacity (the arc draw animates a mask angle). No requests.
  • Accessibility: give each loader role="status" and an aria-label. Under prefers-reduced-motion nothing travels; the loader holds still and breathes in opacity.
  • Browsers: modern evergreen. Without @property the sweep loader steps instead of drawing smoothly; without color-mix the tracks fall back to neutral grey.
  • Licence: upstream is MIT. The full notice is in the stylesheet header.
