Particle Orbs — four WebGL loaders

Four sketches from sketch-threejs by Yoichi Kobayashi, ported from three.js to raw WebGL1 in one dependency-free file. Every orb on this page shares a single GL context, and the page makes zero network requests.

1.0×

1 · The four

Each variant keeps the look of one upstream sketch. All shown at 160 px.

2 · One variant, every size

Hero sizes 160, 96 and 64 px, then two inline sizes. Below 32 px the swarm drops to 16 larger beads so it stays legible; drift needs about 40 px or more to read as a cloud.

3 · In context

The full-screen loader uses whichever variant is selected above.

5 · Dropping it into a page

One file, no build step, no dependency.

<script src="particle-orbs.js"></script>
<div id="loader"></div>

<script>
  const orb = ParticleOrbs.mount(document.getElementById('loader'), {
    variant: 'ember',   // ember | drift | swarm | bloom
    size: 96,           // CSS px; 64 / 96 / 160 hero, 20 inline
    theme: 'dark',      // 'light' | 'dark'
    speed: 1,
    label: 'Loading'
  });

  // when the wait ends
  orb.destroy();
</script>
  • Cost: one file, zero dependencies, zero network requests. Needs WebGL; without it the orb is replaced by a CSS-only gradient of the same size and palette.
  • Frames: pauses itself when scrolled offscreen or the tab is hidden.
  • Accessibility: role="img" with your label; under prefers-reduced-motion it paints one still frame and never animates.
  • Serving: works from file://; no assets are fetched.
  • Licence: upstream is MIT — attribution is in the file header.
