Web Search Radar — live source discovery

Shows an agent searching the web: a query, then sources turning up one by one — dotted placeholder, spinning globe, tick. Ported from solid-thinking-orbs to plain DOM, CSS and inline SVG — no Solid, no Tailwind, no network.

1 · Playground

Each source goes pending, loading, done on its own timing. When the last one lands, the headline flips from “Searching” to “Searched” with a source count. Use the caret to fold the list.

2 · Variants

Same component, different data and options.

3 · One component, every size

The size option is the font size in px; the globe, tick, spacing and rail are all in em and scale with it. 11–12 px is a compact inline status; 16–20 px suits a hero.

5 · Dropping it into a page

Two files, no build step, no dependency.

<!-- load -->
<link rel="stylesheet" href="web-search.css">
<script src="web-search.js"></script>

<!-- markup: a bare host. It inherits your text colour and font. -->
<div id="search-status"></div>

// mount
const search = WebSearchRadar.mount(document.getElementById('search-status'), {
  query: 'token verification best practices',
  sites: [
    { title: 'Verifying tokens safely', url: 'docs.example.org/guides',
      discover: 600, finish: 2400,            // ms from start
      href: 'https://docs.example.org/guides' }  // optional: makes the row a link
  ],
  size: 13,              // px font size
  loop: true,
  defaultOpen: true
});

// tear down (stops the clock, removes the nodes and listeners)
search.destroy();
  • Cost: no animation frame loop. A globe exists only while its row is loading, so a finished list holds no running SVG animation.
  • Pausing: the clock, the CSS loops and the SVG globes all stop when the block is offscreen or the tab is hidden.
  • Accessibility: a visually hidden role="status" announces “Searching” and the final source count once. The caret is a real button with aria-expanded.
  • Reduced motion: the sources still progress (that is information), but nothing moves: a still globe, no shimmer, no ping, no slide, no loop.
