Vue Spinners — eight spinners, no Vue

Extracted from vue-spinner by greyby, which is itself based on Halogen by Yuanyan Cao. The Vue components are reduced to markup and a stylesheet; a small optional script builds the markup and freezes spinners that are offscreen. They take their colour from currentColor and their size from --vs-size.

Dropping it into a page

One stylesheet and one optional script. No build step, no Vue.

JavaScript and HTML 
<!-- load it -->
<link rel="stylesheet" href="vue-spinners.css">
<script src="vue-spinners.js"></script>

// mount, then tear down when the wait ends
const spinner = VueSpinners.mount(document.getElementById('loader'), {
  variant: 'ring',   // clip | ring | moon | dot | bounce | pulse | sync | grid
  size: 64,          // pixels
  color: '#0f766e',  // optional; default is the surrounding text colour
  label: 'Loading'   // accessible text, visually hidden
});
spinner.destroy();

<!-- or, with the CSS alone -->
<span role="status"><span class="vs-ring" style="--vs-size: 64px"></span><span class="vs-sr">Loading…</span></span>
<span role="status"><span class="vs-pulse"><i></i><i></i><i></i></span><span class="vs-sr">Loading…</span></span>
  • Cost: the stylesheet is about 13 KB raw, most of it the two licence notices; the script is about 3 KB. No requests, no animation frames: everything is CSS keyframes on transform and opacity.
  • Frames: the script adds vs-paused while a spinner is scrolled offscreen or the tab is hidden.
  • Accessibility: role="status" with visually-hidden text (vs-sr), added a frame after insert so it is announced. Under prefers-reduced-motion nothing travels; the spinner holds still and breathes in opacity.
  • Licence: upstream is MIT, and so is Halogen, which it is based on. Both notices are in the stylesheet header.
