CSS Spinners - eight pure-CSS spinners

Picked from loading.io css spinner (CC0). Plain markup, plain CSS, no script. Colour is currentColor; every length comes from one property, --cs-size.

All shown at --cs-size: 64px. Of upstream's twelve, dual-ring (a near-twin of ring), circle, heart and hourglass (novelty shapes) are left out.

2 · One property, every size

--cs-size sets the square the spinner fits in; bars, dots and borders all scale from it. 16 px sits in a button or a line of text, 24 px in a toolbar, 64 px as a panel loader.

3 · In context

Inline beside text, inside a disabled button, and in a loading panel. A spinner next to visible words is decorative and hidden from assistive tech; the busy state lives on the button.

4 · Dropping it into a page

One file, no build step, no script.

<!-- 1. load the stylesheet -->
<link rel="stylesheet" href="css-spinners.css">

<!-- 2. markup: one root, its children are the spinner parts -->
<div class="cs-ring" role="status" aria-label="Loading"
     style="color: var(--accent); --cs-size: 32px">
  <div></div><div></div><div></div><div></div>
</div>

<!-- decorative, beside visible text -->
<span class="cs-ring" aria-hidden="true" style="--cs-size: 16px">...</span> Saving
<div class="cs-ring" role="status" aria-label="Loading" style="--cs-size: 32px"><div></div><div></div><div></div><div></div></div>
  • Child counts matter: each spinner needs exactly the number of empty <div>s listed on its card.
  • Reduced motion: children stop, the spinner holds a rest pose and breathes in opacity, slowly. Turn it on in your OS to see it.
