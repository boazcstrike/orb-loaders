Agent Thinking — a reasoning stream

A collapsible “Thinking for 4s…” block that streams an agent’s reasoning line by line, then folds itself into “Thought for 6s”. Ported from solid-thinking-orbs to plain DOM and CSS — no Solid, no Tailwind, no network.

1 · Playground

Click the header to fold the stream. While it is thinking, the stream follows the newest line; scroll up to read back and it lets go.

2 · Variants

Four ways to configure the same component. Each starts on its own clock, so they never march in step.

3 · One component, every size

The size option is the font size in px; line height, the two-line clamp, the viewport cap and the fade depth all scale from it. 11–12 px suits a dense side panel, 16–20 px a hero or presentation.

4 · In context

Above a chat answer. The answer appears when the block reports completion through onComplete.

Why does the upload keep retrying forever?
It retries on every error, including permanent ones. I limited it to network and server errors, capped it at five attempts, and added jitter to the delay.

5 · Dropping it into a page

Two files, no build step, no dependency.

<!-- load -->
<link rel="stylesheet" href="agent-thinking.css">
<script src="agent-thinking.js"></script>

<!-- markup: a bare host. It inherits your text colour and font. -->
<div id="reasoning"></div>

// mount
const thinking = AgentThinking.mount(document.getElementById('reasoning'), {
  sentences: ['Reading the request…', 'Checking the tests…'],  // omit for a sample stream
  delays: [800, 1000],       // ms between lines
  size: 13,                  // px font size
  autoCollapse: true,       // fold into "Thought for Ns" when done
  showTimer: true,
  loop: false,
  onComplete: () => showAnswer()
});

// tear down (stops the clock, removes the nodes and listeners)
thinking.destroy();
  • Cost: no animation frame loop; one timer, woken only when a line or a whole second is due.
  • Pausing: the clock stops when the block is scrolled offscreen or the tab is hidden, so the elapsed time never counts a wait nobody saw.
  • Accessibility: a visually hidden role="status" announces “Thinking” and “Finished thinking” only — not every second. The header is a real button with aria-expanded.
  • Reduced motion: shows the finished reasoning at once, with no shimmer, slide or collapse animation.
