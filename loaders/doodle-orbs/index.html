Doodle Orbs — six generative loaders

Inspired by css-doodle by Yuan Chuan: one cell of CSS repeated over a seeded grid, placed in polar coordinates. Reimplemented as a ~15 KB vanilla generator that emits plain DOM and CSS keyframes. No canvas, no per-frame JavaScript, no dependencies, no network.

1.0×

1 · The six

Each variant is a different recipe over the same cell: polar rings, a golden-angle spiral, rotated petals, orbits, a clipped grid, partial arcs. All shown at 96 px; cell counts are read from the live DOM.

2 · One variant, every size

Three tuned tiers, not one design scaled: up to 32 px (inline) uses fewer, heavier cells; 33–72 px is the control tier; above that, the hero tier gets the full cell count.

3 · In context

Inline at 20 px, the ink inherits currentColor from the surrounding text or button.

4 · Dropping it into a page

One file, no build step, no dependency.

<!-- load it: UMD, so a script tag or a bundler import both work -->
<script src="doodle-orbs.js"></script>
<div id="loader"></div>

// mount, then tear down when the wait ends
const orb = DoodleOrbs.mount(document.getElementById('loader'), {
  variant: 'spiral-galaxy',  // ring-wave | spiral-galaxy | petal-orb | orbiting-cells | grid-sphere | arc-rings
  size: 96,                   // px: tuned at 20 / 64 / 96
  color: 'currentColor',     // any CSS colour, including var(--x)
  speed: 1,
  seed: 7,                    // optional: same seed, same layout
  label: 'Loading'
});

orb.destroy();                // removes the nodes and listeners
  • Cost: the generator runs once at mount. After that the browser animates translate / rotate / scale / opacity on the compositor, so there is no JavaScript per frame.
  • Pausing: animations pause when the orb scrolls offscreen or the tab is hidden.
  • Reduced motion: cells hold a static pose and the whole orb breathes in opacity only.
