Globe Orb — dotted-globe loaders

Five loading states built on COBE, Shu Ding's WebGL dotted globe. One file, no dependencies, no network. Every globe on this page shares a single WebGL context, so a wall of them is as cheap as one.

1.0×

1 · The variants

Each one says something different about the wait. All at 96 px. The globe follows the page theme on its own — flip the toggle and it re-tints without remounting.

2 · One variant, every size

Dot pitch is set from the pixel size, so the lattice stays about 3 px apart at any size instead of dissolving into grey. At 32 px and below, a separate small tuning takes over: sparser dots, ocean dots lifted, a larger marker, no halo.

3 · In context

The 20 px inline variant beside a button label, and a full-screen loading screen using the variant picked above.

4 · Dropping it into a page

One file, no build step, no dependency.

// load it — UMD, so a script tag or a bundler import both work
<script src="globe-orb.js"></script>

// mount into any element, tear down when the wait ends
const orb = GlobeOrb.mount(document.querySelector('#loader'), {
  variant: 'connecting',  // searching | connecting | syncing | idle | inline
  size: 96,                 // px; 32 or below uses the small tuning
  theme: 'auto',          // 'auto' | 'light' | 'dark'
  speed: 1,
  label: 'Connecting'
});

orb.destroy();              // stops the frame loop, removes the node
  • Cost: one file, about 38 KB as authored (the land texture is inlined). No frame is drawn while the globe is offscreen or the tab is hidden.
  • Accessibility: role="img" with an aria-label. With prefers-reduced-motion it paints one still frame and never animates.
  • No WebGL: falls back to a CSS dotted disc. It does not throw.
  • Licence: upstream COBE is MIT — the notice is in the file header.
