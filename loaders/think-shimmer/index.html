Think Shimmer — thinking text & status

Five ways to say "the model is thinking" with text, based on the Think component from Ant Design X (MIT). One CSS file, one JS file, no React, no antd. Ink comes from currentColor, so it re-tints with whatever page it sits on. Each one has a real "done" transition, not a swap.

Each sample works for a few seconds, finishes, then restarts. Turn auto-loop off to drive them with the buttons.

1 · The five variants

Shown at 14 px, the size of a chat message. Press Finish to see the done transition.

2 · One variant, every size

The size option sets a single font-size and every part (icon, dots, gaps, bubble) is in em, so it scales as one unit. 12-16 px suits inline status next to a button or in a table row; 28-40 px suits an empty-state or a full-bleed waiting screen.

5 · Dropping it into a page

Two files, no build step, no dependency.

<!-- load -->
<link rel="stylesheet" href="think-shimmer.css">
<script src="think-shimmer.js"></script>

// mount into any element; ink follows the host's CSS color
const t = ThinkShimmer.mount(document.querySelector('#status'), {
  variant: 'thought',   // shimmer | dots | cycle | thought | steps
  text: 'Thinking…',
  size: 14,
  content: 'Checking the figures against last quarter…'   // thought only
});

t.setText('Reading the report…');
t.done('Thought for 4s');   // spinner -> check, sweep stops
t.destroy();                    // removes nodes, timers, observers
  • Colour: everything is currentColor or a mix of it. Set --ts-done on any ancestor to tint the finished check.
  • Frames: sweep, hop and spin are CSS animations. They pause when scrolled offscreen or the tab is hidden.
  • Accessibility: role="status" carries the text; icons are aria-hidden. prefers-reduced-motion removes the sweep, hop and spin and leaves a slow fade.
  • Licence: upstream is MIT (Ant UED). The notice is in both file headers.
