Thinking Orbs Extended — eight more loaders

The extended states from solid-thinking-orbs, ported to dependency-free vanilla JS — no SolidJS, no build step. Plain 2D canvas: no WebGL, no filters, no SVG. A companion to Thinking Orbs, with the same mount() options and palettes.

1 · The eight states

Every extended state upstream gives its own engine, all shown at 96 px. Dot counts are per frame, measured from the running port. Upstream also lists glacio, flower, sandglass and sand_orbs, but they all run the blooming engine with identical settings, so they are accepted as aliases of blooming and not shown twice.

2 · One state, every size

Upstream ships two hand-tuned designs (64 px and 20 px) — separate designs, not a scale factor. The port picks the 20 px design at or below 32 px and the 64 px one above. Zoom then scales that design linearly so it reads the same at any size; Upstream keeps the library's (size/300)^0.6 curve, correct at 64 px but faint as a hero.

4 · Reduced motion

With prefers-reduced-motion: reduce every state paints one still frame and never animates. Each state freezes at its own moment, picked so the shape reads at a glance. These are those frames, forced on for the preview.

5 · Dropping it into a page

One file, no build step, no dependency.

<script src="thinking-orb-extended.js"></script>
<div id="loader"></div>

<script>
  const orb = ThinkingOrbX.mount(document.getElementById('loader'), {
    state: 'blooming',    // syncing | evolving | building | hypercube | conjuring
                          // | conjuring_static | assembling | blooming
    size: 96,
    palette: 'violet',    // violet | cyan | magenta | jade | slate | mono
    theme: 'light',       // 'light' | 'dark'
    zoom: true,           // scale the tuned design up; leave off at/below 64px
    speed: 1,
    label: 'Loading'
  });

  orb.destroy();          // stops the rAF loop and removes the canvas
</script>
  • Cost: all eight states in one file, zero dependencies, zero network requests.
  • Frames: pauses itself when scrolled offscreen or the tab is hidden, and draws from a reused dot pool, so a frame allocates nothing.
  • Accessibility: role="img" with a per-state label; prefers-reduced-motion paints a still frame.
