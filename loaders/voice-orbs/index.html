Voice Orbs — five orbs, seven states

Audio-reactive voice-assistant orbs from VoiceOrbs by Alexis Munoz, ported to dependency-free vanilla JS on a plain 2D canvas. No React, no WebGL, no build step. Every orb shares one contract: idle, connecting, listening, thinking, speaking, error, disabled, plus a level from 0 to 1 that stands in for audio input.

6 · Dropping it into a page

One file, no build step, no dependency, works from file://.

// load it — UMD, so a script tag or a bundler import both work
<script src="voice-orbs.js"></script>

// mount into any element; theme follows the page unless you pin it
const orb = VoiceOrbs.mount(document.getElementById('assistant'), {
  orb: 'particles',   // particles | wave | ring | equalizer | pulse
  state: 'idle',      // idle | connecting | listening | thinking | speaking | error | disabled
  size: 96,
  theme: 'auto'       // 'auto' | 'light' | 'dark'
});

orb.setState('listening');   // blends over ~0.3s, never cuts
orb.setLevel(micLevel);          // 0..1, call every frame; null = built-in energy
orb.destroy();                   // stops drawing, removes the nodes and listeners
  • Cost: one file, about 50 KB as authored. One shared requestAnimationFrame loop for every orb on the page; an orb offscreen or in a hidden tab costs nothing.
  • Accessibility: role="img" with a label that tracks the state ("Assistant orb, listening"). prefers-reduced-motion paints one static pose per state and never animates.
