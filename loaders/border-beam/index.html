Border Beam — a glowing busy border

The “Border Beam” effect from solid-thinking-orbs, ported to vanilla JS and CSS. A beam travels around a card, slides along an input, or the edge breathes in and out, to say this is working. The animation is CSS; the script only builds three layers.

3 · In context: busy states

Press start. The beam fades in, runs for four seconds, then fades out. The layers stay in the DOM so the next run resumes instantly; aria-busy follows the state.

4 · Dropping it into a page

Two files, no build step, no dependency. The CSS does the animating; the script builds the layers and manages state. Or skip the script and write the layers yourself — see the README.

<!-- load both -->
<link rel="stylesheet" href="border-beam.css">
<script src="border-beam.js"></script>

// any non-void element with a border-radius and a fill of its own
const beam = BorderBeam.mount(document.querySelector('.upload-card'), {
  mode: 'travel',       // travel | line | breathe | halo
  palette: 'spectrum',  // spectrum | mono | cool | warm
  theme: 'auto',        // 'dark' | 'light' | 'auto' (follows the OS)
  duration: 2.2,         // seconds per lap or breath
  strength: 1
});

beam.setActive(false);    // fade out when the work ends; setActive(true) resumes
beam.destroy();            // remove the layers and restore the element
  • Cost: no JS runs per frame. Travel and line animate three registered custom properties; breathe and halo animate opacity and transform of six small gradient lobes per layer, which the compositor handles without repainting.
  • Frames: instances pause when scrolled offscreen, and the browser stops drawing a hidden tab.
  • Accessibility: the layers are aria-hidden; the host gets aria-busy="true" while active. Announce changes in a role="status" region on your side.
  • Reduced motion: prefers-reduced-motion shows a still frame of the border: the arc parked, the pool mid-edge, the lobes at rest. No colour drift.
  • Browsers: needs CSS @property and mask-composite (Chrome and Edge 120+, Safari 16.4+, Firefox 128+). Without them travel and line show a still beam.
