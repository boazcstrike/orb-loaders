Thinking Orbs — all nine loaders

Every state from thinking-orbs, ported to dependency-free vanilla JS — no React, no framework, no build step. Plain 2D canvas: no WebGL, no filters, no SVG. Geometry is verified exactly identical to the upstream engine for all nine states at both tuned sizes; only the ink is re-tinted from grayscale to the chosen palette.

1 · The nine states

Nine verbs an agent can be doing, each a distinct animation. All shown at 96 px. Dot counts are per frame, measured from the running port.

2 · One state, every size

Upstream ships two hand-tuned designs (64 px and 20 px) — separate designs, not a scale factor. The port picks the 20 px design at or below 32 px and the 64 px one above. Zoom then scales that design linearly so it reads the same at any size; Upstream keeps the library's (size/300)^0.6 curve, correct at 64 px but faint as a hero.

5 · Dropping it into a page

One file, no build step, no dependency.

// load it — UMD, so a script tag or a bundler import both work
<script src="thinking-orb.js"></script>

// markup — a bare host element
<div id="site-loader"><div class="orb"></div><p>Loading</p></div>

// mount, then tear down when the wait ends
const orb = ThinkingOrb.mount(document.querySelector('#site-loader .orb'), {
  state: 'breathing',   // any of the nine
  size: 96,
  palette: 'jade',       // 'jade' | 'slate' | 'mono'
  theme: 'light',        // 'light' | 'dark'
  zoom: true,            // scale the tuned design up; leave off at/below 64px
  speed: 1,
  label: 'Loading'
});

window.addEventListener('load', () => {
  document.getElementById('site-loader').classList.add('fade');
  setTimeout(() => orb.destroy(), 500);   // stops the rAF loop
});
