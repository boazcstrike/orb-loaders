Metal Ring — a liquid-metal busy indicator

The “Metal FX” ring from solid-thinking-orbs, ported to dependency-free vanilla JS. A WebGL shader paints a moving metal ring around any button, chip or card to say this is working. One shared shader renders every preset on the page. Without WebGL it becomes a static CSS ring.

1 · Six presets, two shapes

Each card mounts a different preset on a pill button and a circle icon button. Every one reads as busy through aria-busy; the ring itself is decorative.

2 · Size ladder

The ring thickens with the element — 1 px on a 28–40 px pill, 3 px on a 56 px one; 1.5 px on a 24 px circle, 4 px on a 64 px one — so it reads the same at inline and hero sizes. Upstream fixes it at 1 px / 2 px.

4 · No WebGL? A static ring

When a WebGL context can't be created, or is lost, every ring swaps itself for a static CSS conic gradient in the same colours — no throw, same footprint. Force it here with renderer: 'css'. To test a missing context, open this page with ?nowebgl.

5 · Dropping it into a page

One file, no build step, no dependency. Works from http:// or file://.

// load it — UMD, so a script tag or a bundler import both work
<script src="metal-ring.js"></script>

// any non-void element: a button, a chip, a card. Give it a border-radius.
<button id="gen" class="my-button">Generating…</button>

// mount when work starts, destroy when it ends
const ring = MetalRing.mount(document.getElementById('gen'), {
  preset: 'blueberry',   // chromatic | silver | gold | blueberry | rose | copper
  variant: 'button',     // 'button' (pill) | 'circle'
  theme: 'auto',         // 'dark' | 'light' | 'auto' (follows the OS)
  glow: true,            // the wandering halo
  strength: 1
});

ring.setPreset('rose');
ring.destroy();               // stops drawing, removes the canvas, clears aria-busy
  • One shader, many rings: a single 96 px WebGL canvas renders once per preset in use and each ring copies a crop of it. Twenty rings cost about the same GPU time as six.
  • Frames: a ring stops drawing when it scrolls offscreen or the tab is hidden. With no ring left on the page the WebGL context is released.
  • Accessibility: the canvas is aria-hidden; the host gets aria-busy="true" while mounted. Announce the state change in a role="status" region on your side.
  • Reduced motion: prefers-reduced-motion paints one still frame of the metal and parks the halo. Nothing moves.
