Orb Loaders

17 loading indicators — orbs, spinners, progress animations — collected from around the web, each vendored as a self-contained, dependency-free drop-in with its own demo page and licence note.

AI & agent indicators

Thinking Orbs

Nine animated states — working, searching, solving, listening, connecting, weaving, composing, breathing, shaping. Canvas 2D, six palettes, light and dark.

vanilla JS canvas MIT

after Jakub Antalik

Thinking Orbs Extended

Eight more states (syncing, evolving, building, hypercube, conjuring, conjuring static, assembling, blooming) from the SolidJS port. Canvas 2D, six palettes, light and dark. Same options as Thinking Orbs.

vanilla JS canvas MIT

after Mvkweb and Jakub Antalik

Agent Thinking

Collapsible reasoning stream that folds into “Thought for 6s”. Pausable timer, follows the newest line.

DOM CSS MIT

after Mvkweb, Jakub Antalik and Alex Brinza

Web Search Radar

Live source discovery: dots, spinning globe, tick. Headline flips to “Searched N sources”.

DOM SVG MIT

after Mvkweb, Jakub Antalik and Alex Brinza

Think Shimmer

AI “thinking” text and status indicators after Ant Design X’s Think component. Text sweep, typing dots, verb cycle, collapsible thought header and step chain, each with a done transition.

CSS + JS MIT text 5 variants

after Ant Design X

Voice Orbs

Five audio-reactive voice-assistant orbs (dots, lines, ring, bars, core) on one 7-state contract. Raw canvas port of VoiceOrbs.

canvas 2D vanilla JS MIT

after Alexis Muñoz

Orbs & globes

Globe Orb

Five dotted-globe states after Shu Ding’s cobe: searching, connecting, syncing, idle, inline. WebGL, one shared context, light and dark.

vanilla JS WebGL MIT

after Shu Ding

Particle Orbs

Four WebGL particle loaders ported from Yoichi Kobayashi’s sketch-threejs: ember, drift, swarm, bloom. One shared GL context, light and dark, CSS fallback.

vanilla JS WebGL MIT

after Yoichi Kobayashi

Doodle Orbs

Six generative orbs inspired by css-doodle: polar dot rings, spiral galaxy, petals, orbits, a breathing grid and arc rings. One 6 KB file, no JavaScript per frame.

vanilla JS DOM + CSS MIT

after Yuan Chuan (css-doodle)

Busy states

Metal Ring

A liquid-metal WebGL ring around a button, chip or input to show it is busy. Six presets; a static CSS ring when WebGL is missing.

WebGL vanilla JS MIT

after Mvkweb, Jakub Antalik and Alex Brinza

Border Beam

A glowing border that travels or breathes around a card, input or button. Pure CSS animation, four modes, four palettes.

CSS vanilla JS MIT

after Mvkweb, Jakub Antalik and Alex Brinza

CSS spinners

Three Dots

Eight single-element dot loaders from Zongbin’s three-dots: pulse, typing, windmill and more. One div, one custom property, plain CSS.

CSS only MIT 8 variants

after Zongbin

CSS Spinners

Eight classic spinners from loading.io (Taipei), resized from one property and recoloured with currentColor.

CSS only CC0 8 variants

after loading.io

CSS Loaders

Eight single-element ring and orb loaders: arc, sweep, orbit, ripple and more. Plain CSS, currentColor, --cl-size.

CSS only 8 variants MIT

after Vineeth TR

Vue Spinners

Eight spinners extracted from vue-spinner (greyby, after Halogen by Yuanyan Cao), no Vue. 3D rings, moon, bounce, pulse, grid. Optional mount helper.

CSS + tiny JS 8 variants MIT

after greyby (vue-spinner), after Halogen

SpinKit

Eight CSS-only spinners from Tobias Ahlin’s SpinKit (Android port by ybq), retuned: currentColor, one size variable, calm reduced-motion fallback.

CSS MIT 8 variants

after Tobias Ahlin

Activity Indicators

Eight CSS loaders from Loaders.css, the web originals behind NVActivityIndicatorView, now scaling from one size value.

CSS MIT 8 variants

after Connor Atherton (Loaders.css)
